# Instructions for AI Coding Assistants

This repository supports an academic engineering project titled **AI-Based Smart Air Quality Monitoring and Pollution Source Prediction System**.

Future AI coding assistants must follow these rules:

- Keep the project modular and maintain clear separation between documentation, hardware notes, firmware, data processing, AI models, dashboard code, scripts, tests, and results.
- Never fabricate datasets, model outputs, benchmark numbers, graphs, sensor readings, or experimental results.
- Document every major change in the relevant README, documentation file, or code comments.
- Keep the software architecture hardware-independent wherever possible so the AI and dashboard modules can work with different sensor platforms.
- Write clean, readable Python code following common style conventions.
- Add useful comments for non-obvious logic, assumptions, data formats, and model decisions.
- Update `README.md` whenever major features, workflows, setup steps, or dependencies are added.
- Never commit secrets, API keys, passwords, Wi-Fi credentials, private tokens, or personal credentials.
- Use configuration files or environment variables for credentials if external services are added later.
- Prefer reproducible scripts and documented workflows over manual, undocumented steps.
