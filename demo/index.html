AI-Based Smart Air Quality Monitoring and Pollution Source Prediction System

ESP32 sensor node · Bluetooth LE · on-device AI on Android · 16×2 LCD — 82 s, with voice-over

Source code on GitHub Download video (MP4, 20 MB)

What the video shows

  1. Sensor node: ESP32 with MH-Z19 CO₂, PMS7003 particles, DHT11 and MQ135, powered by a 2S Li-ion pack
  2. LCD pages: pollutants, climate and gas index, AI status from the phone, system status
  3. AirQ AI app: dashboard and AQI, live trends, pollution source identification (Naive Bayes)
  4. Device and sensor health, 15/60-minute forecasts (RLS regression) and ventilation alerts
