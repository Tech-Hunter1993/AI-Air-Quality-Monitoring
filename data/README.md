# Data

This folder stores project datasets.

```text
data/
|-- raw/
|-- processed/
`-- sample/
```

## Rules

- Store original datasets or sensor readings in `raw/`.
- Store cleaned datasets generated by scripts in `processed/`.
- Store small synthetic demonstration data in `sample/`.
- Do not manually edit raw data.
- Do not add fake or fabricated datasets.
- Document every dataset in `docs/Dataset.md`.

No experimental dataset has been added yet. The file in `sample/` is synthetic and is only for tests and demonstrations.
