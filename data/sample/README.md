# Synthetic Sample Data

This folder contains a very small synthetic CSV created only for testing and demonstration of the preprocessing pipeline.

The file `synthetic_air_quality_sample.csv` is not experimentally collected sensor data. It intentionally includes data-quality issues such as missing values, invalid timestamps, duplicate rows, duplicate timestamps, out-of-range values, and text in numeric columns.

Do not use this sample for model training, experimental results, or academic performance claims.
