## Folder-Level Documentation

Each major project folder includes a short README describing its intended use and restrictions.

## Documentation Rules

- Do not add fabricated results, datasets, or evaluation values.
- Cite external sources when literature, standards, datasets, or thresholds are used.
- Update relevant documents when project decisions change.
- Keep placeholders where information is not finalized.
- Record assumptions clearly.
