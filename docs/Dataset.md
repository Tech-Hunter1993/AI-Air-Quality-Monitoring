# Dataset

## Purpose

This document will describe the datasets used in the project, including source, structure, license, preprocessing, and limitations.

## Current Dataset Status

No dataset has been added to this repository yet.

Datasets must not be fabricated. Any dataset used in this project must come from a documented public source, institutional collection process, or validated sensor readings collected by the project team.

## Dataset Selection Criteria

The selected dataset should include as many of the following as possible:

- Timestamped air quality readings.
- Pollutant measurements such as PM2.5, PM10, CO, NO2, SO2, and O3.
- Environmental variables such as temperature and humidity.
- Location or station metadata.
- Sufficient time range for forecasting.
- Clear license or usage permission.
- Documentation of measurement units.

## Planned Folder Usage

```text
data/
|-- raw/
|   `-- original datasets or collected sensor data
`-- processed/
    `-- cleaned datasets generated by preprocessing scripts
```

Raw data should remain unchanged. Processed data should be reproducible from raw data and scripts.

## Preprocessing Plan

Planned preprocessing steps:

- Verify column names and units.
- Convert timestamps to a standard format.
- Remove duplicate records.
- Handle missing values using documented rules.
- Remove impossible or invalid readings.
- Normalize or scale values if required by the model.
- Create time-based features such as hour, day, month, or lag values.
- Split data into training, validation, and test sets.

## Data Quality Checks

Before model training, the following checks should be performed:

- Missing value percentage per column.
- Duplicate row count.
- Outlier detection summary.
- Date range and sampling interval validation.
- Unit consistency.
- Target variable distribution.

## Dataset Versioning

If multiple dataset versions are used, document:

- Version name.
- Date added.
- Processing script used.
- Changes from previous version.
- Reason for change.

## Restrictions

- Do not commit private or restricted datasets without permission.
- Do not commit large files unless approved by the project team.
- Do not modify raw data manually.
- Do not create synthetic or fake readings and present them as real data.
